## Status choices

- **Planned:** You know what is needed, but the final file is not ready.
- **Draft:** A temporary or unfinished version is included.

## Rules

- Keep the original source link.
- Record the license shown when you downloaded the asset.
- Do not write "free" as the license. Name the actual license or permission.
- Mark your own work as "Original work."
- Mark AI-generated assets and name the tool used when the assignment permits them.
- Store required attribution text in this file and in the final product when the license requires it.
- Do not use an asset when its permission is unclear.
