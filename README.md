## Project summary

Bracer Guild - Pom Party is a WPF Project made on Visual Studio that is a Tetris inspired game from the Trails Series world. The goal is 
to stack blocks of the same color to clear your row which will earn you points on the CP Gauge. This Gauge can then be used to either Defend yourself
or attack your opponent. Defending clears rows on your board while attacking adds rows to your opponents board. Strategize, assess, and help
grow the orbal net in a fun and exciting way.

## How to open and run the project

1. Open project with Visual Studio
2. Project located in src folder as "Bracer Guild - Pom Party.vbproj"
3. Click run (or press F5)
4. Application opens as a window
5. Title Screen then begin gaming.

## Controls or main workflow

Arrow Keys - Move Left, Right, or Down to fall faster
Enter Key - Use CP Gauge for attack or defense
